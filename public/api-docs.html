⚡ Exachanger API Documentation

RESTful API for Exachanger digital currency exchange platform

Base URL: https://exachanger.com/api

🔓 Public Endpoints

GET /exchange-rates
Get all exchange rates (all currency pairs)
Example: /api/exchange-rates
GET /exchange-rate/{from}/{to}
Get specific exchange rate by currency pair
Example: /api/exchange-rate/USDT/USDC
GET /products
Get all active products (AirTM, PayPal, USDT, etc.)
Example: /api/products
GET /blockchains/{productName}
Get available blockchains for a crypto product
Example: /api/blockchains/USDT
GET /payment-methods/{productName}
Get payment methods for a product
Example: /api/payment-methods/USDT
POST /register
Register new user account
Body: {"name":"John","email":"john@test.com","password":"123456","password_confirmation":"123456"}
POST /login
Login user (returns token)
Body: {"email":"john@test.com","password":"123456"}

🔒 Protected Endpoints Requires Bearer Token

GET /profile
Get authenticated user profile
Header: Authorization: Bearer {your_token}
PUT /profile
Update user profile
Header: Authorization: Bearer {your_token}
POST /logout
Logout user (invalidate token)
Header: Authorization: Bearer {your_token}
POST /transaction/create
Create new exchange transaction
Header: Authorization: Bearer {your_token}
POST /transaction/upload-proof
Upload payment proof image
Header: Authorization: Bearer {your_token}
GET /transaction/{trxId}
Track transaction status
Example: /api/transaction/TRX-69E323135EF3B
GET /my-transactions
Get all transactions of authenticated user
Header: Authorization: Bearer {your_token}

📝 Notes

  • All responses are in JSON format
  • For protected endpoints, add header: Authorization: Bearer {your_token}
  • Token obtained from /register or /login response
  • Images are served from /img/product/ and /img/blockchain/
